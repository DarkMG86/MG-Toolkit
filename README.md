# MG Toolkit

## English (Français ci-dessous)

It is a standalone batch script with several features aimed at maintaining a PC equipped with at least Windows 10.

> [!IMPORTANT]
> In order to use the program in the best conditions, please follow these instructions :
> + Disable your antivirus for the duration of use to avoid false positives
> + If necessary, the Windows Update installation packages (function 19) can be downloaded via this ([link](https://1drv.ms/f/c/011dbcd351618514/EhSFYVHTvB0ggAG56gMAAAABzpb74buvreHFXUhLGtM1Ow)) and are to be placed in the same directory as the program. This link also gives access to all updates (mainly in French) from Windows 3.1 to date.

> [!WARNING]
> This program is provided as is and without warranty of any kind !
