# MG Toolkit

It is a standalone batch script with several features aimed at maintaining a PC equipped with at least Windows 10.

> [!WARNING]
> In order to use the program in the best conditions, please follow these instructions :
> 1) Disable your antivirus for the duration of use
> 2) Delete all downloaded files after the use is over
> 3) If necessary, the Windows Update installation packages (function 19) can be downloaded via this ([link](https://1drv.ms/f/c/011dbcd351618514/EhSFYVHTvB0ggAG56gMAAAABzpb74buvreHFXUhLGtM1Ow)) and are to be placed in the same directory as the program. This link also gives access to all the updates (mainly in French) from Windows 3.1 to date.
