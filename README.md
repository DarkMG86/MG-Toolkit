# MG Toolkit

## (English below)

Il s'agit d'un script batch autonome avec plusieurs fonctionnalités visant à maintenir un PC équipé d'au moins Windows 10.

> [!IMPORTANT]
> Afin d'utiliser le programme dans les meilleures conditions, veuillez suivre ces instructions :
> + Désactivez votre antivirus pendant toute la durée de l'utilisation afin d'éviter les faux positifs
> + Si nécessaire, les packages d'installation Windows Update (fonction 19) peuvent être téléchargés via ce ([lien](https://1drv.ms/f/c/011dbcd351618514/EhSFYVHTvB0ggAG56gMAAAABzpb74buvreHFXUhLGtM1Ow)) et doivent être placés dans le même répertoire que le programme. Ce lien donne accès à tous les fichiers d'installation et mises à jour (principalement en français) que j'ai trouvé sur le web depuis MS-DOS jusqu'à ce jour.

> [!WARNING]
> Ce programme est réalisé pendant mon temps libre, il est donc fourni tel quel et sans garantie !



## English

It is a standalone batch script in French with several features aimed at maintaining a PC equipped with at least Windows 10.

> [!IMPORTANT]
> In order to use the program in the best conditions, please follow these instructions :
> + Disable your antivirus for the duration of use to avoid false positives
> + If necessary, the Windows Update installation packages (function 19) can be downloaded via this ([link](https://1drv.ms/f/c/011dbcd351618514/EhSFYVHTvB0ggAG56gMAAAABzpb74buvreHFXUhLGtM1Ow)) and are to be placed in the same directory as the program. This link gives access to all installation files and updates (mainly in French) that I have found on the web since MS-DOS to date.
